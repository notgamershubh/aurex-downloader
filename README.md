# AUREX Downloader

A lightweight, browser-only tool for previewing and downloading direct media file URLs.

## Supported formats
- Video: MP4, WebM, MOV, M4V
- Audio: MP3, M4A, OGG, WAV, AAC

## Run locally
Open `index.html` in a modern browser, or serve this folder with any static web server.

## Deploy with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then save.
4. The site will be published at `https://notgamershubh.github.io/aurex-downloader/`.

## Important
Use only direct media links for content you own, public-domain material, or content you have permission to download. This project does not download YouTube pages, bypass DRM, or evade platform restrictions. Browser and host CORS/download policies may limit some URLs.
